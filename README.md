## ✨ 功能特性

- **📋 历史记录**: 自动记录复制过的内容。
- **📂 智能分类**:
  - 自动将内容识别为 **文本** 📄、**图片** 🖼️ 或 **文件** 📁。
  - 创建 **收藏列表** ⭐ 来归档和管理重要内容。
- **🔍 便捷搜索**: 通过全局搜索栏快速找到您需要的内容。
- **👁️ 快速预览**: 
  - **右键点击** 任意文本条目，即可打开详细的预览窗口。
  - 富文本显示支持。
- **🎨 现代自适应 UI**:
  - **主题切换**: 支持浅色、深色及跟随系统模式。
  - **可调整面板**: 自由调整喜欢的面板宽度。
- **📊 数据管理**:
  - **收藏导出**: 收藏文本导出为 JSON 文件。
- **🪄 AirDrop 快捷共享**:
  - 拖拽文件到屏幕顶部刘海区域，自动弹出 AirDrop 共享面板。
  - 支持多文件同时拖拽共享。
- **🧩 刘海菜单栏图标管理**:
  - 在带刘海的 MacBook 上，访问因菜单栏空间不足而隐藏在刘海后的应用图标。
  - 右键点击 iClipboard 菜单栏图标即可查看；普通点击可触发对应图标，按住 **Option** 点击可尝试展开其菜单。
  - 使用前需要为 iClipboard 授予辅助功能权限。
- **📷 图像工具**:
  - **截图与标注**：自由框选或智能选取窗口、界面元素，添加形状、箭头、文字、画笔和马赛克，支持撤销与重做。
  - **悬浮贴图**：将截图或剪贴板图片贴在屏幕上，支持多张贴图、等比例缩放、透明度调整和置顶。
  - **图片文字提取**：在支持的设备上直接划选图中文字，或一键复制图像全文；识别在本机完成，无需上传图片。
  - **取色与保存**：查看像素放大预览并复制 HEX 色值，将图片复制到剪贴板或保存为 PNG。
- **🌐 全局划词翻译**:
  - 支持火山引擎、豆包 AI 和微软三种翻译服务。
- **⚙️ 个性化**:
  - **全局快捷键**: 随时随地瞬间唤出面板。
  - **捕获控制**: 精细控制文本、富文本、图片和文件的捕获开关。
  - **历史记录限制**: 自定义保留的条目数量，高效管理存储空间。
  - **窗口置顶**: 点击 Pin 保持窗口悬浮，方便对照使用。
  - **划词翻译**: 在设置中配置豆包 sessionid、选择翻译服务并授予辅助功能权限后，开启全局划词翻译。

## 🛠️系统要求

- macOS 13.6 或更高版本
- Xcode 15+ (用于源码构建)

## 📦 安装说明

### 源码构建
1. 克隆仓库:
   ```bash
   git clone https://github.com/tenoms/iClipboard.git
   ```
2. 在 Xcode 中打开 `iClipboard.xcodeproj`。
3. 构建并运行 (Cmd+R)。

## 💡 使用指南

### 基础操作
- **打开**: 点击菜单栏图标 📋 唤出面板。
- **复制**: 点击列表中的任意条目，即可将其重新复制到剪贴板。
- **固定窗口**: 点击顶部的 **Pin** 图标 📌，可保持窗口持久显示。

### 图像工具
- **开始截图**：右键点击菜单栏图标，选择“区域截图…”，也可使用面板底部的图像工具菜单或自定义截图快捷键。拖动框选区域，按 `Esc` 取消。
- **智能选取**：在设置中选择“不检测”“仅窗口”或“检测元素”；启用后，单击高亮区域即可选中对应窗口或界面元素。
- **标注与输出**：选区确定后，在工具栏中选择标注工具。工具栏靠近鼠标释放位置显示，拖动其空白处或状态文字可移开遮挡；完成后可复制、保存或贴到屏幕上。
- **提取文字**：在支持的设备上划选图片文字，按 `⌘C` 复制所选内容。使用“复制图像全文”按钮或已配置的快捷键可提取整张选区或当前贴图的文字。
- **使用贴图**：通过“贴出剪贴板图片”或截图工具栏的贴图按钮创建悬浮图片。拖动空白处，或按住 `Option` 拖动图片来移动；拖动边缘、角落或滚动鼠标可缩放。工具栏提供透明度、置顶及关闭操作，菜单栏右键菜单可统一显示、隐藏或关闭全部贴图。
- **屏幕取色**：截图时将鼠标移到目标位置，借助像素放大预览查看颜色，右键复制 HEX 色值；框选后按住 `Option` 可查看像素预览。
- **保存图片**：在设置中指定默认保存目录后可直接保存；未指定时选择保存位置。图片以 PNG 格式保存，自动命名并避免覆盖同名文件。历史记录中的图片也可右键编辑、贴图或保存。

首次截图需要授予屏幕录制权限。图片文字识别在本机离线完成，无需登录或上传图片。图像工具目前不支持长截图、GIF 或视频录制。

### 进阶功能
- **预览**: **右键点击** 文本条目，可打开独立的大窗口进行查看。
- **删除**: 鼠标悬停在条目上，点击 **垃圾桶** 图标 🗑️ 即可删除。顶部提供“全部清除”功能。
- **收藏**: 点击 **星标** 图标 ⭐ 将条目加入收藏列表。
- **操作刘海后的图标**: **右键点击** iClipboard 菜单栏图标，在列表中选择被刘海遮挡的应用图标；按住 **Option** 点击可尝试直接展开对应菜单。
