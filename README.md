iClipboard 一个小巧精致的 macOS 剪贴板管理工具。

[English Documentation](README_EN.md)

---

## ✨ 功能特性

- **📋 历史记录**: 自动记录复制过的内容。
- **📂 智能分类**:
  - 自动将内容识别为 **文本** 📄、**图片** 🖼️ 或 **文件** 📁。
  - 创建 **收藏列表** ⭐ 来归档和管理重要内容。
- **🔍 便捷搜索**: 通过全局搜索栏快速找到您需要的内容。
- **👁️ 快速预览**: 
  - **右键点击** 任意文本条目，即可打开详细的预览窗口。
  - 富文本显示支持。
- **🎨 现代自适应 UI**:
  - **主题切换**: 支持浅色、深色及跟随系统模式。
  - **可调整面板**: 自由调整喜欢的面板宽度。
- **📊 数据管理**:
  - **收藏导出**: 收藏文本导出为 JSON 文件。
- **🪄 AirDrop 快捷共享**:
  - 拖拽文件到屏幕顶部刘海区域，自动弹出 AirDrop 共享面板。
  - 支持多文件同时拖拽共享。
- **🧩 刘海菜单栏图标管理**:
  - 在带刘海的 MacBook 上，访问因菜单栏空间不足而隐藏在刘海后的应用图标。
  - 右键点击 iClipboard 菜单栏图标即可查看；普通点击可触发对应图标，按住 **Option** 点击可尝试展开其菜单。
  - 使用前需要为 iClipboard 授予辅助功能权限。
- **📷 图像工具**:
  - 区域截图、图像标注、马赛克、撤销/重做，以及无损 PNG 保存和复制。
  - 多窗口贴图，可独立缩放、调透明度、置顶并识别文字。
  - 系统 Live Text 原位划词与 Apple Vision 离线全文识别，不再打开独立识字窗体；屏幕和图片取色。
  - 新图片保留原图，历史列表按需显示轻量缩略图。详见 [图像工具使用说明](docs/IMAGE_TOOLS.md)。
- **🌐 全局划词翻译**:
  - 支持火山引擎、豆包 AI 和微软三种翻译服务。
- **⚙️ 个性化**:
  - **全局快捷键**: 随时随地瞬间唤出面板。
  - **捕获控制**: 精细控制文本、富文本、图片和文件的捕获开关。
  - **历史记录限制**: 自定义保留的条目数量，高效管理存储空间。
  - **窗口置顶**: 点击 Pin 保持窗口悬浮，方便对照使用。
  - **划词翻译**: 在设置中配置豆包 sessionid、选择翻译服务并授予辅助功能权限后，开启全局划词翻译。

## 🛠️系统要求

- macOS 13.6 或更高版本
- Xcode 15+ (用于源码构建)

## 📦 安装说明

### 源码构建
1. 克隆仓库:
   ```bash
   git clone https://github.com/tenoms/iClipboard.git
   ```
2. 在 Xcode 中打开 `iClipboard.xcodeproj`。
3. 构建并运行 (Cmd+R)。

## 💡 使用指南

### 基础操作
- **打开**: 点击菜单栏图标 📋 唤出面板。
- **复制**: 点击列表中的任意条目，即可将其重新复制到剪贴板。
- **固定窗口**: 点击顶部的 **Pin** 图标 📌，可保持窗口持久显示。

### 图像工作流
- 从菜单栏右键菜单或面板底部取景框打开截图、贴图；框选后直接用选区下方工具栏操作，非选区仅轻微变暗。不再提供冗余的“截图识别文字”菜单项。
- 截图中“贴图”快捷键直接贴当前选区并退出；设置中的“复制图像全文”（原“识别屏幕文字”）在框选后复制选区全文并退出，或在贴图获得焦点后复制该贴图全文并保留窗口。复用已有快捷键组合，仅在对应窗口内本地处理、不注册全局按键，其它窗口可正常输入 `Shift+C` 等组合；不启动额外截图，不增加 `⌘⇧C` 绑定。右键截图像素取色。
- 支持的设备上可原位划词后 `⌘C` 复制所选文字；没有文字选择时 `⌘C` 复制图片。文字／绘图标注不触发重复识别，不混入选区原文；马赛克改变时按遮挡后的底图更新识别。
- 贴图支持原位划词，全文使用统一的“复制图像全文”配置快捷键，仅作用于当前焦点贴图。空白处或按住 Option 拖动贴图，图片区域滚轮直接缩放；更小尺寸自动隐藏工具条，放大后恢复。不内置 `⌘W` 关闭；配置的关闭贴图快捷键仅关闭当前键盘焦点贴图，不按鼠标或最近窗口猜测目标，关闭按钮／Esc 保留。
- 设置默认保存目录后直接保存，不再弹面板；未设置才选择位置。文件名 `iclipboard_yyMMdd_HHmmss.png`，并发重名不覆盖。
- 截图支持“不检测／仅窗口／检测元素”三级智能框选，默认仅窗口；取色色块与放大镜并入截图。
- 捕获贴图保持原选区屏幕尺寸。快捷键直接录制，支持修饰键+Esc；仅历史、截图和贴图使用普通 Carbon 全局注册，全文／关闭使用窗口本地快捷键，不增加手动组合界面。
- 图片条目右键可编辑、贴图或保存；文字在截图／贴图中直接选择，不再提供“识别文字”菜单或独立“图片文字识别”窗体。字号、线宽、马赛克滑块显示实时数值。
- 屏幕工具首次使用需要屏幕录制权限；已有图片 OCR 离线运行、不需要登录、不上传图片。全局划词翻译服务与设置保持独立。
- 当前图像工具不包含长截图、GIF 或视频录制。

### 进阶功能
- **预览**: **右键点击** 文本条目，可打开独立的大窗口进行查看。
- **删除**: 鼠标悬停在条目上，点击 **垃圾桶** 图标 🗑️ 即可删除。顶部提供“全部清除”功能。
- **收藏**: 点击 **星标** 图标 ⭐ 将条目加入收藏列表。
- **操作刘海后的图标**: **右键点击** iClipboard 菜单栏图标，在列表中选择被刘海遮挡的应用图标；按住 **Option** 点击可尝试直接展开对应菜单。
